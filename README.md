# Callibri Rust App

Rust GUI-приложение для работы с нейрогарнитурой Callibri через Neurosdk2.

## Зависимости

### Linux (Ubuntu/Debian):
Скачайте и установите neurosdk2:
https://github.com/BrainbitLLC/linux_neurosdk2/tree/main/package

### Windows:
Скачайте и установите neurosdk2:
https://github.com/BrainbitLLC/neurosdk2-cpp

## Запуск

```bash
cargo run
